Outreach desk · find, write, send

Real firms, found on the open web

The whole database is one JSON file. Claude searches for brokers, reads each firm's own contact page, and keeps only the addresses printed there, with the page as proof. A short Python script sends one plain-text email a minute.

01 · FINDSearch, then read their own pages

A web search lists candidate firms. outreach/find.py fetches each contact page and picks out the addresses in the HTML.

02 · TWO RULESNever guess. Keep the source.

No address is built from a name pattern. Every address is stored with the exact page it was printed on.

03 · SENDOne a minute, plain text

outreach/send.py reads the file, sends what is unsent over SMTP, flips sent to true and saves.
